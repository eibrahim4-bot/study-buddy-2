# Focus Friend 🐾
A desktop study companion for Erini, Arly, and Sydney, built with Electron.

## Current prototype
- Starts with a small, transparent, always-on-top pet in the bottom-left corner.
- The pet has a gentle idle bounce and tail wag; hover to see a small hint.
- Drag the pet to move it. Click it to open the full Focus Friend dashboard.
- The dashboard contains the timer, points, streak, animal picker, and reward shop.
- Progress is saved locally in the app.

## Run it
1. Install Node.js (LTS) from https://nodejs.org/
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm start`

## Notes
This is a hackathon prototype. Automatic monitoring of other desktop applications and websites is not yet implemented; the dashboard's distraction control is a demo. The pet window is designed to be a small desktop companion rather than a second full dashboard window.
